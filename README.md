# 📊 Portafolio de Análisis de Datos en Excel

¡Hola! Bienvenido a mi repositorio. Aquí documento mi proceso de aprendizaje y mi dominio práctico de Microsoft Excel enfocado en el análisis de datos. 

Este espacio contiene diversos proyectos y ejercicios prácticos que simulan entornos empresariales reales, resolviendo problemas a través de la limpieza, estructuración y visualización de información.

## 🗂️ Índice de Proyectos

*(Añade a esta lista cada vez que subas una nueva carpeta con un proyecto)*

* **[01_Limpieza_y_Filtros](./01_Limpieza_y_Filtros):** Identificación y eliminación de registros duplicados para asegurar la integridad de bases de datos.
* **[02_Funciones_Busqueda_y_Logica](./02_Funciones_Busqueda_y_Logica):** Cruce de tablas con `BUSCARV` y toma de decisiones automáticas con la función `SI`.
* **[03_Dashboards_Interactivos](./03_Dashboards_Interactivos):** Construcción de reportes de ventas usando Validación de Datos, listas desplegables y la función `SUMAR.SI`.

## 🛠️ Habilidades Técnicas Demostradas
- **Limpieza de Datos:** Formato condicional, eliminación de duplicados.
- **Modelado y Relación:** VLOOKUP / BUSCARV.
- **Cálculos Dinámicos:** SUMIFS / SUMAR.SI.
- **Lógica de Negocios:** Funciones IF / SI.
- **Visualización:** Gráficos de columnas, diseño de Dashboards interactivos.
